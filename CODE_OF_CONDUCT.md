# Code de conduite

Nous voulons une communauté accueillante, respectueuse et constructive.

Les participants s'engagent à :
- respecter les personnes, leurs expériences et leurs opinions ;
- accueillir les critiques constructives ;
- privilégier les échanges utiles et bienveillants ;
- éviter le harcèlement, les insultes, les attaques personnelles et les propos discriminatoires ;
- agir avec professionnalisme dans les discussions publiques.

Les mainteneurs peuvent modifier, masquer ou supprimer les contributions qui ne respectent pas ces règles et prendre des mesures adaptées en cas de comportement abusif.

Pour signaler un problème, contacte les mainteneurs par un canal privé du dépôt.
