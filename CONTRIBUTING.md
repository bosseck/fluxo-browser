# Contribuer à FLUXO

Merci de vouloir contribuer. FLUXO est un projet expérimental : les contributions doivent être petites, vérifiables et documentées.

## Avant de commencer
1. Ouvre une issue pour discuter d'un changement important.
2. Vérifie la feuille de route et l'état réel du projet.
3. Ne prétends pas qu'une fonctionnalité planifiée est déjà implémentée.

## Règles
- TypeScript strict et code lisible.
- Pas de secrets, jetons, clés privées ou certificats dans Git.
- Toute modification IPC doit vérifier l'émetteur, les arguments et les permissions.
- Toute modification du contenu web doit préserver l'isolation entre contenu distant et privilèges Electron.
- Ajoute des tests adaptés et documente les limites connues.

## Pull requests
Décris le problème, la solution, les tests exécutés, les impacts sécurité et les captures d'écran si l'interface change. Les changements sensibles doivent être relus avant fusion.
