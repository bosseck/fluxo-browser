# Configuration de la licence

FLUXO adopte la licence **GNU Affero General Public License v3.0 uniquement**.

- Identifiant SPDX : `AGPL-3.0-only`
- Texte officiel : https://www.gnu.org/licenses/agpl-3.0.html

Avant toute publication de code source, ajouter le texte intégral officiel de la licence dans un fichier nommé `LICENSE` à la racine du dépôt. Ne pas utiliser un résumé ou un texte incomplet comme substitut.

La licence du code ne concède pas automatiquement de droits sur la marque, le nom, les logos ou les éléments graphiques FLUXO.
