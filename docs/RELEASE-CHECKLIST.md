# Checklist avant publication

- [ ] Confirmer les fonctionnalités réellement implémentées.
- [ ] Exécuter tests unitaires, intégration et tests manuels.
- [ ] Vérifier les dépendances et vulnérabilités connues.
- [ ] Auditer IPC, preload, navigation, permissions et téléchargements.
- [ ] Vérifier qu'aucun secret, certificat ou fichier personnel n'est commité.
- [ ] Ajouter le texte intégral officiel AGPL-3.0-only dans LICENSE.
- [ ] Vérifier les mentions de licence des dépendances et ressources.
- [ ] Construire et tester l'installateur sur une machine propre.
- [ ] Signer les binaires et sécuriser le mécanisme de mise à jour.
- [ ] Publier les notes de version et les limites connues.
- [ ] Obtenir un audit indépendant avant une promesse de sécurité forte.
