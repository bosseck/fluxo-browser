# État du projet FLUXO

Dernière mise à jour : 2026-11-23

## Phase actuelle

Fondation du dépôt et prototype expérimental.

## Plateforme prototype

- Windows : prototype Electron / Chromium / React / TypeScript en cours de validation.
- Android : architecture à concevoir séparément avec un moteur adapté. Electron n'est pas une cible Android.

## Non prêt pour la production

Les fonctions suivantes nécessitent encore conception, implémentation et tests :
- protection anti-pistage et blocage publicitaire robuste ;
- profils et navigation privée correctement isolés ;
- coffre de mots de passe et intégration d'autofill ;
- synchronisation E2EE avec gestion des clés et récupération ;
- assistant IA à déclenchement explicite ;
- système de mise à jour signé ;
- audit de sécurité indépendant.

Ne pas présenter les fonctions planifiées comme déjà disponibles.
